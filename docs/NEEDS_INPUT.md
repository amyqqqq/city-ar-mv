# 下一階段工作與需求

目前無需大型模型即可執行原素材預覽、匯入、組裝及測試。

1. HTTPS 手機驗收：需要 Android Chrome / iOS Safari 可開啟的可信任 HTTPS 網址，並由設備使用者允許相機。先測原版，再測新版。目前沒有公開部署或外部通道。
2. 生成 provider：預設 ComfyUI 8188／ACE-Step 8001 未連線，常見安裝資料夾未找到候選。使用既有安裝需確認位置、啟動方式與 workflow/API；使用遠端服務需選定模型、權利範圍及費用設定。現有插槽不會自動下載模型或消耗額度。
3. AI 內容：製作一位一致的虛構成年角色、三種都市空間及一軌原創無人聲 Trap；先用 manual import 或配置完成的 provider 產出素材與 metadata。
4. 動態素材：目前為程式化靜態圖層回退。後續加入 alpha matte／序列或 H.264+mask、五鏡頭 workflow、分身與城市變形；4GB 顯存不預設可跑大型影片模型。
5. 原始工程：只有 HTML 發佈匯出；完整 Studio 編輯需原始 ECS／場景工程與版本資訊。現有 PoC 不依賴它，也不改寫閉源引擎。
6. 正式發布前：確認素材與隨附引擎權利範圍，完成效能、透明邊緣、音畫偏差及雙手機測試。

建議順序：HTTPS 手機 baseline → 分層尺度／事件 → 原創音樂與角色參考 → provider → 五段動作 → 手機壓縮與效能驗收。對應完整規格 Phase 3–5。
